# buyruk.net/blog - static archive

A frozen, static copy of the **buyruk.net** blog (2006-2014), made in November 2026 when
the site moved off its old WordPress hosting. `site/` is served by Cloudflare Pages;
every post keeps its original address under `/blog/`, and `buyruk.net/` still forwards
to `/blog/`. The search box uses Google site search.

`scripts/` and `.github/workflows/` hold the tools that made the copy (they need the old
server, so they only work until it is switched off).
